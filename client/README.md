# TEC Digitalito

Frontend con React + Vite.

## Requisitos

- Node.js 18+
- npm

## Instalacion

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

Tambien puedes ejecutar desde la carpeta del cliente:

```bash
cd client
npm run dev
```

## Build de produccion

```bash
npm run build
```

## Preview local del build

```bash
npm run preview
```
